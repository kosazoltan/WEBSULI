# Repó-saját skillek (WEBSULI)

Ide kerülnek a CSAK erre a repóra érvényes Hermes-skillek: `.hermes/skills/<repo>-<téma>/SKILL.md`
(+ opcionális `references/`, köztük témaspecifikus `references/TRAP.md`).
Gyári/globális skillt ide ne másolj, és ne módosíts.

Záró hurok skill-ellenőrzése: minden új `.hermes/projekt/TRAP.md` sor `skill-hivatkozás` cellája
létező skill-útvonal (pl. `.hermes/skills/<név>/SKILL.md`) vagy `nincs-skill: <indok>`.
