# Cél (tulajdonosi követelmény)

A WEBSULI „pótlások” dokumentációjának felvétele a főágra: a félbemaradt munkák leltára (68 tétel), a terv (50 szelet) és a
végrehajtási utasítás, valamint a tulajdonosi döntések (D-01…D-16, 2026-11-19) átvezetése. Csak dokumentáció; kód, teszt, CI vagy
kapukonfiguráció nem változhat.

Keress:
- titok, token, személyes adat (e-mail-cím, név, telefonszám) vagy belső URL megjelenését a dokumentumokban;
- olyan, ügynököknek szóló felszólító mondatot, amely jóváhagyás nélkül fizetős / külső / visszafordíthatatlan műveletre utasít;
- a tulajdonosi döntések (D-01…D-16) és a terv szeleteinek egymásnak ellentmondó leírását;
- hivatkozást nem létező fájlra, függvényre, kapcsolóra vagy PR-ra;
- a háromfázisú rend hibáját (a végrehajtási utasítás a teljes `docs/specs/<név>.md` útvonallal hivatkozzon a tervre).

Hibát keress, ne megerősítést.
