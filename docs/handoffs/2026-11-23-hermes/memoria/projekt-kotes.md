Repó: `D:/repo/WEBSULI` ↔ projekt: a Claude Code oldalsáv **„WEBSULI”** csoportja (`cg-<csoport-azonosító>`).
Minden ebben a repóban indított sessiont ebbe a csoportba kell sorolni (`move_sessions`, group_id fent).
A teljes repó–csoport térkép: `~/.claude/scripts/repo-projekt-kotes.json`. A tudás itt halmozódik: [[projekt-tudasterkep]], [[retro-naplo]].
