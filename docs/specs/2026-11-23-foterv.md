## 3. Kötöttségek

1. **Egy gép, egy kapusor (C-72):** egyszerre egy helyi push- / PR-kapu vagy vak kör fut; egy szelet egy köre (kapu + vak kör + CI)
   mérve 1,5–2 óra. Reális áteresztés: napi 6–8 beolvasztás. A terv ezért sorrend, nem párhuzamos ütem.
2. **Közös fájlok:** a `docs/agent-csapdak.md` és a közös terv-dokumentumok szinte minden ágon ütköznek — egy szelet vak köre csak az
   előtte álló, ugyanazt a fájlt érintő PR beolvadása UTÁN indul (2026-11-23-i tanulság, C-TGM-1).
3. **Konvergencia-törvény:** 3 egymást követő NEM, vagy 2 NEM nem csökkenő blokkolószámmal → nincs új kör; követelmény egy
   mondatban, hibaosztály-leltár, kisebb szelet, végül tulajdonosi döntés űrlapon.
4. **Halmozott ágak:** minden PR egyedül is hagyja változatlanul az éles működést (kapcsoló a lánc alján, alapból KI).
5. **Csak helyben lévő munka:** a 2. táblázat „félkész” oszlopának nagy része nincs a távoli gépen — az első PR-ig adatvesztési
   kockázat (gépcsere, takarítás).
