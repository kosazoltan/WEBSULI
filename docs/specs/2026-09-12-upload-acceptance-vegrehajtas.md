# Végrehajtás

1. AGENTS.md, docs/lesson-improvement.md, két tananyag-skill és előző átvételi jelentés beolvasása. git status ellenőrzés; más munka megőrzése.
2. source/generation-release-preflight.local.mts csak olvasási ellenőrzése és futtatása; aktív gyártás elkülönítése.
3. Chrome normál admin Tananyag készítése / Feltöltés. TESZT cím, dokumentált fájlválasztóval a kijelölt szövegfájl. Jogosultsági elutasításkor emberi fájlkiválasztás szükséges; tilos cookie/auth vagy DOM fájlinjektálással megkerülni.
4. Tananyag készítése gomb; látható állapot és tárolt futás megfigyelése. Újratöltés után ugyanaz a futás. Hiba esetén pontos lépés és napló rögzítése; sikert tilos állítani.
5. Kész eredmény visszaolvasása és forráshűség, séma, bankok, négy lap, pontozás, mobil/asztali megjelenés vizsgálata. Közzétett URL tényleges megnyitása.
6. Csak az új tesztleckén javítójelölt, ellenőrzés, mentett alkalmazás, visszaolvasás. A kész jelölt és alkalmazott tartalom külön státusz.
7. docs/handoffs/ alatt PASS/FAIL/NOT RUN eredmény és pontos blokkoló. Kódváltozás nélkül új teljes unit suite nem szükséges; az éles próba az elfogadási kapu.
