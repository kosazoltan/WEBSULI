# Windows x64 fejlesztési cél

Tulajdonosi döntés: Windows fejlesztés és CI kizárólag x64-en. A Linux CI és a csomagkezelő platformlistája változatlan.

- E1: a natív Windows-job egy x64 futtatón teljes npm ci-t, doctor:arch próbát, egységtesztet és buildet futtat.
- E2: a kötelező Playwright E2E összesítő bukik, ha a natív job nem sikerült.
- E3: az aktív üzemeltetési és fejlesztési utasítások egyetlen Windows-célt neveznek meg.
