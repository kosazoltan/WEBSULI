# ContentCard
A chapter of lesson text: the numbered chapter head, the explanation card with highlighted key terms, and the 'Figyelj!' box.

- Lesson text uses the band's body style (`body-explorer` 22px … `body` 16px); never below it.
- Key terms: `ws-key` highlight (companion hue at 22%), bold. At most three per paragraph.
- 'Figyelj!' (watch out) box: `warning-bg` / `on-warning-bg`, written from the lesson's own misconceptions.
- Keep a paragraph to about four sentences; split longer explanations.
