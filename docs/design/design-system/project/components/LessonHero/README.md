# LessonHero
The lesson's first card: title, subject and grade chips on the left, the approved picture on the right.

- **Picture:** a topic cover from the catalogue when the lesson's subject and keywords match, else the band hero (`pickLessonArt`, `source/shared/design-assets.ts`). No text is ever drawn on the picture.
- **Mascot:** only in the 1–5. bands — the fox portrait with the band's speech bubble on `bubble`/`on-bubble`.
- **Consumer provides:** title, subject, grade, the chosen picture and its catalogue `alt` text.
- **Phones:** one column, the picture on top at 16:9.
