# LessonTabs
The five pages of a lesson: Tananyag, Módszerek, Feladatok, Kvíz, Ismétlés — one row, equal widths, an icon per tab.

- The selected tab: `soft` fill, `title` label, 2px inner `accent` ring. Others: `muted` label.
- Arrow keys, Home and End move between tabs (roving tabindex); targets are at least 44px.
- The Ismétlés tab appears only when the lesson has flashcards.
