# Buttons
Primary (`strong` / `on-strong`) and secondary (`secondary` / `on-secondary`) buttons, 44px tall, `radius-sm`.

- One primary action per card. The raw `accent` with white text is never a button (3–5.: 3.88:1, 11–12.: 3.75:1).
- Focus: the two-tone ring (`focus` outside, `focus-inner` inside).
