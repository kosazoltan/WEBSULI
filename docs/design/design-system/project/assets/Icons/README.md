Subject icons (1:1). **Use the band set first:** `icon-<subject>-<band>` — one approved icon for every subject taught in a band (NAT 2020 matrix in `source/shared/subject-icons.ts`, 72 icons). Bands: `explorer` 1–2., `adventure` 3–5. (glossy 3D toy-like), `studio` 6–8., `laboratory` 9–10., `future` 11–12. (clean soft 3D, cooler palette, maturing motifs). The lesson stores the chosen id in `art.subjectIcon`; the player loads it from `/api/design-assets/<id>`. The older age-group icons (`-young` and the bare subject ids) are kept only as a fallback. Untaught subject × band pairs have no icon.
